# NEXO (versión gratuita, sin IA)

Publicación gratis con GitHub Pages:
1. Crea cuenta en github.com.
2. Crea un repositorio público llamado nexo.
3. Sube estos 5 archivos (index.html, manifest.json, sw.js, icon-192.png, icon-512.png) con "Add file > Upload files" y pulsa "Commit changes".
4. Settings > Pages > Source: Deploy from a branch > Branch: main, carpeta / (root) > Save.
5. Abre https://TUUSUARIO.github.io/nexo/ e instálala desde el menú del navegador del celular.
